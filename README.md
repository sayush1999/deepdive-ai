# Deepdive-ai
Interactive, immersive video learning on GCP.
1. **Interactive mode** - pause any video, ask a question, get answers in different perspective modes.
2. **Generate mode** - upload docs/PPT/PDF, get a curated learning video.
3. **Multilingual** - Cloud Translation + Text-to-Speech for answers and narration.
4. **Audience insights** - interaction events land in BigQuery; creators see a confusion heatmap.
5. **Personalization** - learner profile (Firestore) suggests default mode and language.

See docs/architecture/overview.md and the phase plan in docs/roadmap.md.
